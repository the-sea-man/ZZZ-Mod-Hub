## 6 Key Call Chains

**1. Mod Install (drag-and-drop or file picker)**
`App.tsx onDrop` -> `invoke("install_mods")` -> `install::install_mods` -> `extract_mod_zip` + `determine_mod_category` -> `fs_ops::move_mod_to_category` -> emits `install-progress` event -> `useAppStore` refreshes via `scan_mods_folder`

**2. Auto-Sort Unassigned**
`LibraryView "Auto-Sort"` -> `invoke("auto_assign_mods")` -> `install::auto_assign_mods` -> `determine_mod_category` per mod -> `fs_ops::move_mod_to_category` -> returns sorted list

**3. Toggle Mod (enable/disable)**
`ModCard toggle` -> `invoke("toggle_mod")` -> `game_ops::toggle_mod` -> `state_tracker` reads `d3dx_user.ini` -> renames folder `DISABLED_` prefix -> writes state cache

**4. GameBanana Download**
`GameBananaView` -> `invoke("download_gb_mod")` -> `gamebanana::download_gb_mod` -> streams file, emits `download-progress` -> `useDownloadStore` tracks queue -> on complete triggers `install_mods`

**5. Mod Fix (version upgrade)**
`ModCard "Fix"` -> `invoke("check_mod_fixable")` -> `mod_fixer::analyze_mod_for_fixes` (loads fixer DB) -> opens `FixModModal` -> `invoke("fix_mod")` -> `apply_mod_fix`: remaps hashes + `.buf` bytes + bone indices -> creates `.zmm-backup/`

**6. Non-Destructive Thumbnail Prewarming & Display**
`LibraryView` / `ModCard` -> `invoke("get_cached_thumbnail")` -> `thumbnail_cache::compute_thumbnail_path` -> if cached, returns path immediately; if missing, runs Rayon parallel downscale to 360x450 JPEG in `%APPDATA%/thumbnails/` leaving source image read-only -> frontend loads fast local thumbnail.
