# Security policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2.0 | :x:                |

## Reporting a vulnerability

If you discover a security issue or vulnerability (such as archive path traversal or IPC boundary serialization errors):

1. **Do not open a public GitHub issue.**
2. Report the vulnerability privately through a [GitHub Security Advisory](https://github.com/the-sea-man/ZZZ-Mod-Hub/security/advisories/new) or by contacting the maintainers directly.
3. Include a description of the issue, reproduction steps, and proof of concept if available.

We will review the report promptly, validate the issue, and release a patch via Tauri updater before public disclosure.
